# Sign Tools license + update server (Cloudflare Worker)

Deployed by Cloudflare Workers Builds from this folder (branch `signtools-worker`).
- `/api`   — panel API (activate / refresh / deactivate / latest)
- `/admin` — admin page (keys, releases)
- D1 database `signtools` holds keys, releases and the Ed25519 signing key.
- Custom domain: https://signtools.ballsticker.co.th
