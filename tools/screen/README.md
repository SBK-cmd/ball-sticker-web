# จอเล็กตั้งโต๊ะ (Turing 3.5") — โชว์ตัวเลขร้าน

แอปหลังร้าน (เครื่องที่ล็อกอินสิทธิ์เงินเข้า) คำนวณ 4 ตัวเลขแล้วเขียนเอกสาร `screenStats/today` (ตัวเลขล้วน ไม่มีข้อมูลลูกค้า)
สคริปต์ `ball_screen.py` บนคอมที่เสียบจอ อ่านเอกสารนั้นแล้ววาดภาพ 480×320 เขียนทับไฟล์พื้นหลังของโปรแกรม Turing

ตัวเลข: ต้องส่งวันนี้ (due = วันนี้ ยังไม่ส่ง) · งานค้าง/เลยกำหนด (due < วันนี้ ยังไม่ส่ง) · เงินเข้าวันนี้ (ไม่รวมบัญชีที่ซ่อน) · พัสดุกำลังส่ง (shipped และยังไม่ถึงลูกค้า)
ถ้าแอปไม่ส่งข้อมูลมาเกิน 15 นาที จอจะขึ้น "--" และข้อความ "ข้อมูลเก่า" แทนตัวเลข (กันเข้าใจผิดว่าเป็นตัวเลขปัจจุบัน)

## ตั้งค่า (ครั้งเดียว)
1. กฎ Firestore (Firebase Console → Firestore → Rules) เพิ่มบล็อกนี้ให้ **อ่านได้เฉพาะเอกสารนี้**:
   ```
   match /screenStats/{doc} {
     allow read: if true;
     allow write: if request.auth != null;
   }
   ```
2. บนคอมที่เสียบจอ: ติดตั้ง Python 3 และรัน `pip install pillow`
3. คัดลอก `config.example.json` เป็น `config.json` แล้วกรอก `apiKey` และ `outPath`
4. `outPath` ต้องเป็นไฟล์เดียวกับที่เลือกใน Turing → Background Setting (ธีม "blank for image")
5. ทดสอบ: `python ball_screen.py --demo` (ภาพตัวอย่าง) แล้ว `python ball_screen.py --once`
6. ใช้งานจริง: `python ball_screen.py` (วนทุก 30 วินาที) — ตั้งให้รันตอนเปิดเครื่องด้วย Task Scheduler ได้
