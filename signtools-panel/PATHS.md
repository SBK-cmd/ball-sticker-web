# พาธ Windows/Mac อัตโนมัติ — เบต้าแก้พาธ

## หลักการ

ใบงานยังเก็บพาธเดิมไว้ การเปิด/สแกนจะเทียบโฟลเดอร์รากตามการตั้งค่าของเครื่องปัจจุบัน แล้วต่อพาธย่อยให้เอง ไม่เขียนทับพาธใน Firestore ไม่ย้าย/ลบไฟล์ และไม่ค้นหาไฟล์ชื่อคล้ายกันแทน

ตัวอย่าง: `\\B-NAS\ballsticker\S40670\ท้ายเจ้าสมุทร.eps` เทียบกับราก Mac ที่ผู้ใช้เลือกจริง เช่น `/Volumes/ballsticker` จะเปิด `/Volumes/ballsticker/S40670/ท้ายเจ้าสมุทร.eps` โดยพาธ Windows ในใบงานยังคงเดิม การเทียบย้อนกลับ Mac → Windows ใช้หลักเดียวกัน

พาธเป็นข้อมูลสำหรับเปิดแก้แบบ/สแกนเท่านั้น **ถ้าใบงานสแกนและบันทึกเส้น Kiss/Die มาร์ค และค่าตัดครบแล้ว เครื่องที่ไม่มี AI/EPS หรือเข้า NAS ไม่ได้ยังพรีวิวและส่งตัดจาก snapshot ได้** แต่ต้องมี Illustrator + SignTools รุ่นรองรับ โหลดใบงานได้ และเชื่อมถึง Graphtec พร้อมตั้ง IP/พอร์ตถูกต้อง

## ตั้งค่าครั้งแรกบนแต่ละเครื่อง

1. เชื่อม NAS ใน Finder/Explorer และตรวจว่าโฟลเดอร์ที่ต้องการเปิดได้จริงก่อน
2. ใน SignTools เปิดคิวงาน แล้วกด **ตั้งค่า NAS / พาธ**
3. ช่อง Windows จะเสนอรากที่พบในพาธใบงาน เช่น `\\B-NAS\ballsticker` หากมีหลายรากให้เลือกให้ตรง NAS/ไดรฟ์นั้น ไม่เดาจากชื่อไฟล์
4. บน Mac กด **เลือกโฟลเดอร์ของเครื่องนี้** แล้วเลือกโฟลเดอร์รากเดียวกันที่เมานต์จริง เช่นโฟลเดอร์ `ballsticker` ใน Finder ระบบกรอกพาธ Mac ให้ ไม่ต้องคัดลอกพาธทีละไฟล์
5. บน Windows ปุ่มเดียวกันจะกรอกช่อง Windows; ช่อง Mac ใส่/เลือกตามรากที่ใบงานอ้างอิง การตั้งค่าคู่หนึ่งต้องหมายถึงพื้นที่เดียวกันจริง
6. ตรวจทั้งสองรากแล้วกด **บันทึกคู่นี้** จากนั้นกดเปิด/สแกนไฟล์จากใบงานได้ทุกไฟล์ใต้รากนั้น

การตั้งค่าจำเฉพาะแผง/บัญชีผู้ใช้ OS ของเครื่องนี้ใน localStorage ไม่ซิงก์ไปเปลี่ยนค่าเครื่องอื่น ไม่รวมไว้ในข้อมูลลูกค้า และยังไม่สร้างระบบแชร์ค่าพาธอัตโนมัติทั้งร้าน

หากอีกเครื่องใช้ `S:\` แทน UNC สามารถตั้งคู่ `S:\` ↔ ราก Mac ที่ตรงกันเพิ่มได้ แต่ต้องรู้ว่าเป็น share เดียวกันจริง หากเปิดได้หลายพาธตามการตั้งค่าจะหยุดให้แก้คู่ที่กำกวม ไม่เลือกพาธแรกเงียบ ๆ

## สิ่งที่รองรับ

- Windows drive แบบ absolute และ UNC, พาธ POSIX/macOS และ file URL ที่ถูกต้อง
- เทียบราก Windows ไม่สนตัวพิมพ์เล็ก/ใหญ่; ฝั่ง Mac ไม่ลดตัวพิมพ์ทั้งชื่อให้ผิดไฟล์
- ชื่อไทย ช่องว่าง และ Unicode NFC/NFD ในการเทียบ โดยไม่เปลี่ยนตัวสะกดของชื่อไฟล์ที่ใช้เปิด
- คั่นพาธตาม OS และตรวจขอบเขตโฟลเดอร์ ป้องกันชื่อรากที่ขึ้นต้นคล้ายกัน เช่น share กับ share-other
- ใช้รากที่เจาะจงที่สุดหากตั้งคู่โฟลเดอร์ซ้อนกัน
- เปิดไฟล์พิมพ์/ไฟล์ตัด และสแกนได้ผ่านพาธที่เทียบแล้ว
- ผูกไฟล์ที่เปิดอยู่บน Mac ไม่เพิ่มซ้ำเมื่อเป็นอ้างอิงเดียวกับพาธ Windows ตามคู่ที่ตั้งไว้อย่างชัดเจน
- ตรวจเวลาแก้ไขของไฟล์ที่เทียบแล้วก่อนส่งตัดแบบ best-effort ถ้าไม่มีต้นฉบับจะใช้ snapshot ไม่ทำให้ส่งตัดไม่ได้

## การป้องกันไม่เปิดไฟล์ผิด

ตรวจว่าไฟล์ปลายทางเป็นไฟล์จริงก่อนเรียก Illustrator ถ้าราก NAS เข้าไม่ได้จะให้ตรวจการเชื่อมต่อ/เลือกโฟลเดอร์ใหม่ ถ้า NAS เข้าได้แต่ไฟล์ย่อยไม่อยู่ จะบอกให้ตรวจไฟล์ที่ย้าย ยังไม่ไล่ค้นหาไฟล์ใน NAS

ถ้าพบมากกว่าหนึ่งไฟล์จากคู่รากที่ตั้งไว้ หรือมีอีกทางเลือกที่ยังตรวจไม่ได้ เช่น NAS ออฟไลน์/ไม่มีสิทธิ์ จะหยุด ไม่เลือกไฟล์ที่บังเอิญเปิดได้แทน ส่วนพาธเดิมที่เป็นของ OS ปัจจุบันและมีไฟล์จริงจะใช้พาธเดิมโดยตรง

ไม่รับพาธ relative, `..`, Windows device path, URL ที่ไม่ใช่ file URL หรือชื่อที่แปลงเป็น Windows แล้วมีอักขระต้องห้าม ชื่อไฟล์ POSIX ที่มี backslash จะไม่แปลงเป็นโฟลเดอร์ Windows เงียบ ๆ

**ไม่ได้เมานต์ NAS/กรอกรหัสผ่าน NAS ให้อัตโนมัติ ไม่ได้ทำลายนิ้วมือหรือหาไฟล์ที่ย้ายโฟลเดอร์ (งานข้อ 2 ส่วนค้นหาไฟล์ยังแยกต่างหาก)** การเมานต์เปลี่ยนชื่อหรือพาธต้นทางย้ายใน OS เดียวกันไม่ได้ถูกเดาแปลงจากชื่อ share ให้เอง ต้องตรวจรากและคู่ที่ตั้งไว้ให้ตรงตำแหน่งจริง

## ทดสอบบนเครื่องจริง

ใช้สำเนา/ใบงานทดสอบ ไม่ลบหรือย้ายไฟล์ต้นฉบับเพื่อทดลอง:

1. บน Mac ตั้งคู่รากจาก Windows แล้วกดเปิด EPS ชื่อไทยจากคิว ตรวจว่าเปิดไฟล์ที่ตรงชื่อและโฟลเดอร์จริง
2. ตั้งค่าตัดและสแกน ตรวจ Kiss/Die มาร์ค/ค่าตัด แล้วตรวจพาธ Windows ในใบงานยังไม่เปลี่ยน
3. บน Windows โหลดใบงานที่ผูกไฟล์จาก Mac ตั้งคู่ราก แล้วกดเปิด/สแกน ตรวจว่าทั้งสองเครื่องใช้ชุดเดียวกัน
4. บนเครื่องที่ไม่มีต้นฉบับ ให้ไม่เชื่อม NAS แต่คงอินเทอร์เน็ต/เครือข่ายเครื่องตัด โหลด snapshot แล้วพรีวิว/ตัดเศษวัสดุ ตรวจเส้น มาร์ค และค่าแรง ไม่ต้องเปิดไฟล์หรือสแกนใหม่
5. ลองปุ่ม ① และ **② สร้างแผ่นงาน** ก่อนใช้ผลิตจริง หากไม่ผ่านให้หยุดและใช้ชุด rollback ตามเลขสูงสุดที่ปล่อยจริง

cd signtools-panel/tests
